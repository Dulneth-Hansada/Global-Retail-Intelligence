# Global Retail Intelligence – Power BI Dashboard

An interactive three-page Power BI dashboard developed using the Global Superstore dataset to explore global retail performance, product profitability, customer segments, and shipping operations.

## Project Overview

This project is my first Power BI dashboard project, created as part of my learning journey in Business Intelligence and Data Analytics.

The dashboard transforms raw retail data into meaningful visual insights through interactive charts, filters, and data analysis.

## Dashboard Pages

### 1. Global Overview
- Overall sales, profit, orders, and customer performance
- Global sales distribution by country
- Monthly sales trends
- Sales performance by region
- Top 10 countries by sales

### 2. Product & Profit Analysis
- Sales performance by product category
- Profit analysis by sub-category
- Product sales and profitability comparison
- Discount impact on profit
- Top 10 products by sales

### 3. Customer & Shipping Insights
- Yearly sales trends by customer segment
- Shipping mode distribution
- Customer sales and profit analysis
- Regional sales performance by segment
- Profit contribution by product category

## Tools & Technologies
